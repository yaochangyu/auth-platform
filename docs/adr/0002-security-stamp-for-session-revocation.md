# 0002. 透過安全戳記 (Security Stamp) 實現跨裝置會話註銷

- **狀態 (Status)**: 已採納 (accepted)
- **日期 (Date)**: 2026-09-28

## 背景脈絡 (Context)

當會員成功重設密碼或變更密碼時，必須立即強制終止該會員在所有裝置與瀏覽器上的既有登入會話，以防止已外洩或遭盜用的會話繼續被惡意利用。由於認證採用 HttpOnly Cookie，若沒有伺服器端的失效信號，純無狀態 Cookie 無法主動廢止其他遠端瀏覽器中的有效會話。

## 決策 (Decision)

我們決定在 `members` 資料表引入 **安全戳記（Security Stamp）** 機制。
登入成功時，系統將當前的安全戳記寫入 HttpOnly Session Cookie 的 Claims 中。每當會員變更密碼、重設密碼或請求全域登出時，系統便自動重新生成該會員的安全戳記。Cookie 認證中介層在驗證請求時，會比對 Cookie 中的戳記與資料庫（或快顯快取）中的最新戳記是否一致；若不一致則立即視為會話失效，達成跨裝置 Session 的瞬間註銷。

## 後果與權衡 (Consequences)

- 確保憑據一旦異動，所有歷史登入裝置即刻被踢出，具備最高安全性。
- Cookie 認證檢驗過程需定期或在請求時向資料庫/快取比對會員的最新安全戳記。
